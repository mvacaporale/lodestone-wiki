# Cognitive Load Theory

Cognitive Load Theory — you have only so much working-memory capacity to learn new concepts. Roughly speaking, you can hold ~4 chunks of working memory at a time, of which only 1-2 can be novel. Best practice is to anchor learning on 2-3 known chunks while introducing only 1-2 new ones at a time.

When learning, working memory serves three distinct types of load:

- **Intrinsic** — chunks needed to load the concept into memory
- **Extraneous** — chunks spent managing how the material is presented (ideally minimal, if not zero)
- **Germane** — working memory needed to integrate the learned material
