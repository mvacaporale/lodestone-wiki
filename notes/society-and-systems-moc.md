# Society and Systems

This MOC synthesizes thinking on why societal systems consistently fail to serve human flourishing—and what might be done about it.

---

## Core Framework

**The fundamental problem**: Misaligned optimization in a multi-agent world, under bounded attention and slow, noisy feedback.

We build systems that optimize for *proxies* (money, clicks, votes, grades) faster than we can align those proxies to what we actually value (wellbeing, truth, belonging, stewardship).

> "We're optimizing the wrong variables at scale—and doing it very efficiently."

## Key Mechanisms

### Why Proxies Fail
1. **Goodhart's Law** — Once a measure becomes a target, it ceases to be a good measure
2. **Phase lag** — Feedback loops (climate, social trust) operate slower than optimization cycles
3. **Information fragmentation** — No shared epistemic ground to recognize gaming
4. **Institutional inertia** — Legacy KPIs embedded in careers, policy, infrastructure
5. **Machine-speed optimization** — AI/algorithms outpace human adaptation

### System-Specific Dysfunctions

| System | Proxy Optimized | What's Lost |
|--------|-----------------|-------------|
| Social Media | Engagement, time-on-site | Truth, connection, mental health |
| Healthcare | Revenue per procedure | Root-cause healing, prevention |
| Education | Test scores, rankings | Creativity, intrinsic motivation |
| Economy | GDP, quarterly profit | Ecological stability, meaning |

## Design Principles for Realignment

### Anti-Fragile Metrics
- **Multi-objective bundles** — Never a single KPI
- **Counter-metrics (anti-KPIs)** — Automatic dampers when proxy ↑ but value ↓
- **Costly-to-fake measures** — Ground truth, audits, randomized checks
- **Metric rotation** — Assume Goodhart; sunset clauses; red-team budgets

### Meta-Criteria
- **Ashby's Requisite Variety** — Governance complexity must match environment complexity
- **Open information flows** — Interoperable data, provenance, transparency
- **Adaptive cadence** — Review cycles, rotation schedules, sunset dates

| Unconscious Amplification | Conscious Realignment |
|---------------------------|----------------------|

| Optimization at machine speed without wisdom | Human judgment in the loop with transparent overrides |
| Fragmented epistemics, outrage cycles | Rebuilt shared maps, deliberative synthesis |
